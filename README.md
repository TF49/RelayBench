# RelayBench · 中转站稳定性批量测评

给一批「中转站地址 + 该站创建的 API Key」，自动测出每个站点、每个模型的**报错、速度、稳定性**，再让一个评审模型**打分点评**，输出排行榜。适配 new-api、sub2api，以及 one-api / 其他 OpenAI 兼容中转。

## 启动

需要 Python 3.9+，不需要安装任何依赖，也不需要 npm。

```bash
python server.py            # 默认端口 8000，可加 --port 8080
# 浏览器打开 http://127.0.0.1:8000/
```

Windows 可以直接双击 `start.bat`。

> 必须通过 `server.py` 打开页面，不能直接双击 `index.html`：所有请求要经过本地代理（sub2api 默认不允许跨域，new-api 不暴露响应头）。

## 使用流程

1. **站点**：「添加站点」或「批量导入」（每行 `地址 Key [名称]`），会自动识别站点类型、查余额、拉模型列表，并按「常用模型关键字」预选模型；可点「选择模型」调整。
2. **测试**：点站点卡片上的「测试」（只测这个站），或右上角「开始测试全部」。测试页实时显示每个站点×模型的进度、成功率、首字延迟、报错和请求日志，可随时停止。
3. **报告**：跑完自动跳到报告：AI 综合点评、余额消耗、排行榜（可按各列排序），点击行看规则分构成、请求时间线、错误样本、质量题答案和 AI 评语。可导出 CSV / JSON。站点卡片上也会显示最近一次每个模型的得分、成功率、首字延迟和报错。
4. **设置（可选）**：AI 评审**默认开启**，自动从已添加站点里挑最强的模型（Claude Sonnet/Opus、GPT-5 等）当评委；也可以指定站点和模型，或单独填一个评审渠道，用「测试评审连接」确认可用。这里还能调整请求数、并发、超时。
5. **历史**：每次测试自动保存在本机浏览器，可回看、删除。

## 测什么、怎么打分

在「站点」或「测试」页一键切换测试档位（默认**快速**）：

| 档位 | 稳定性请求 | 质量题 | 每个模型 |
|---|---|---|---|
| 快速（默认） | 3 | 2（算术、JSON） | 5 次 |
| 标准 | 6 | 4（算术、指令遵循、JSON、推理） | 10 次 |
| 深度 | 15 | 4 | 19 次 |

稳定性请求都是流式短问答；质量题本地按标准答案判分。也可以在「设置」里自定义次数。

| 规则分维度 | 分值 | 规则 |
|---|---|---|
| 可用性 | 45 | 成功率 × 45 |
| 速度 | 25 | 首字延迟 P50（≤1s 满分，≥10s 零分）15 + 输出速度 P50（≥60 tok/s 满分，≤5 零分）10 |
| 稳定性 | 15 | 首字延迟变异系数（≤0.2 满分，≥1.0 零分）10 + 总耗时 P95/P50（≤1.5 满分，≥4 零分）5 |
| 质量 | 15 | 质量题通过率 × 15 |

**综合分 = 规则分 × 0.6 + AI 分 × 0.4**（权重可在设置里改；没有 AI 分时等于规则分）。等级：S ≥ 90，A ≥ 80，B ≥ 70，C ≥ 60，D < 60。

错误会自动归类：Key 无效、额度不足、无可用渠道、模型不存在、限流、上游错误、超时、网络失败、流中断、空回复、请求被拒。

### 计时说明

- 代理**流式透传、不重试**，所以首字延迟真实，错误也不会被重试掩盖。
- 浏览器对同一主机最多 6 个并发连接，因此全局并发上限为 6；代理会回传上游耗时（`X-RB-Upstream-Ms`），前端据此扣除本地排队时间。
- 模型名含 `claude` 时默认走 `/v1/messages`，其他走 `/v1/chat/completions`；可在站点卡片上改协议。

## 界面与动效

高端简洁风格：暖石色中性底 + 单一青绿强调色、Geist 字体、双层边框面板、浮动胶囊导航，自动跟随系统浅色/深色。

动效基于 **GSAP 3.13**（本地 `vendor/gsap/`，含 Flip / SplitText / ScrollTrigger / ScrambleText / DrawSVG / CustomEase），并用原生 JS 移植了 react-bits 的效果：BlurText/SplitText 标题入场、CountUp 数字滚动、DecryptedText 解密文字、SpotlightCard 光斑卡片、Magnet 磁吸按钮、TiltedCard 倾斜卡片、ClickSpark 点击火花、DotGrid 点阵背景、SoftAurora 环境光、AnimatedList 列表入场、PillNav 导航指示器、ShinyText 流光文字、BorderGlow 运行描边、Radar 扫描指示、GlareHover 掠光、Stepper 引导步骤，以及排行榜 Flip 重排和评分环描边动画。

- **不影响计时**：测试运行期间自动暂停持续性动画（环境光、点阵重绘），只保留轻量的 transform/opacity 过渡。
- 「设置 → 界面」可关闭动效；系统开启「减少动态效果」时自动关闭。
- 字体与 GSAP 都在本地，离线可用。

## 隐私

- Key 默认**只在内存里**，刷新页面后需要重新输入；勾选「记住 Key」才会存进本机浏览器 IndexedDB。
- 测试记录和导出文件**不含任何 Key**。
- 代理只监听 `127.0.0.1`，并校验请求来自本页面，其他网页无法借用它。

## 开发

```bash
node --test tests/                  # 核心模块单测（无需安装依赖）
python tools/mock_relay.py          # 模拟中转站，端口 9001
```

模拟站点：`http://127.0.0.1:9001/na`（new-api 风格）、`/s2`（sub2api 风格）、`/bad`（慢且不稳），Key 用任意 `sk-test...`；评审模型填 `judge-model`。

```
server.py            本地静态服务 + 流式代理
js/core/             纯逻辑（不碰 DOM）：client 请求与 SSE 计时、relay 站点适配、errors 错误分类、
                     stats 统计、scoring 规则分、judge 评审、probes 题库、runner 调度
js/ui/               各视图（sites / run / report / history / settings）
js/state.js          状态与持久化；js/store/db.js IndexedDB
tools/mock_relay.py  模拟中转站
docs/superpowers/specs/  设计文档
```
